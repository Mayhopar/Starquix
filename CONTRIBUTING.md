# Contributing to Starquix

Thanks for helping. Build and test steps are in the [README](README.md#development).

- Keep each pull request to one change.
- Bug fixes need a regression test.
- Run `cd app && npm run test:run` and `cd desktop && npm test` before you open the pull request.

By opening a pull request you agree that your contribution is licensed under the project's [MIT License](LICENSE).
